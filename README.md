# MindVenture — Plataforma de Apoyo Psicológico con IA y VR

Proyecto de Grado UNAD — Wilmar Delgado, Nelson Rueda — 2026.

## Stack
- Frontend: React + Vite + Tailwind + React Three Fiber
- Backend: Node.js + Express + MongoDB (Mongoose)
- IA: DeepSeek API
- VR: Three.js + WebXR (vía React Three Fiber)
